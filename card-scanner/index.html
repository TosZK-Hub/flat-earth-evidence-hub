Beating glare and getting a clean read
  • Tilt, don't flatten: angle the card 10–15° away from the light so reflections slide off the number and name.
  • Soft light: shade the card with your hand, or face away from overhead lights and windows. Avoid the phone torch on holos.
  • Sleeves and top-loaders add glare, so slide the card out if you can. Slabs work best with Ximilar on.
  • Hold steady: wait for the camera to focus. With Auto-scan on, it fires when it can read the number.
  • Full arts: the number sits over the artwork. Get closer so it fills more of the frame, or use Photo for a full-resolution shot.
  • One Piece: the code (e.g. OP05-119) is bottom-right. Set the toggle to One Piece for the best read.
