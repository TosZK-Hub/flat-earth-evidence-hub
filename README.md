# Flat Earth Evidence Hub

Devil’s-advocate **online classroom** for flat-Earth community evidence: sequenced modules/lessons, steelmanned FE claims with sources, honest evidence labels (established / hypothesis / speculation). Flat Earth is **not** presented as proven science.

**Live:** https://toszk-hub.github.io/flat-earth-evidence-hub/

## Start here
- `index.html` — course landing
- `course.html` — syllabus + progress
- `course.json` — module/lesson map
- `lessons/` — foundations, lab, capstone
- `posts/` — evidence lessons (Bedford, horizon, maps, Antarctica, imagery)
- `tools.html` — Labs (horizon calculator)
- `practice.html` — claim-tester lab
- `videos.html` — classroom video shelf
- `about.html` — how this classroom grades evidence
